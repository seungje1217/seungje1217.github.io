데이터를 인터넷으로 전송할 때는 패킷을 중간에서 가로채는 **스니핑(Sniffing)** 이나 데이터 변조와 같은 보안 위협이 존재한다. 

**IPSec(IP Security)** 은 이러한 문제를 해결하기 위해 사용되는 대표적인 보안 프로토콜이다.

IPSec은 IP 계층에서 동작하며, 데이터의 기밀성, 무결성, 인증을 제공하여 안전한 통신을 가능하게 한다.

## VPN과 IPSec

먼저 **VPN(Virtual Private Network, 가상 사설망)** 은 공용 인터넷을 이용하면서도 마치 전용선을 사용하는 것처럼 안전하게 통신할 수 있도록 만들어 주는 기술이다.

VPN을 구현하는 대표적인 기술이 IPSec이다.

VPN에서는 주로 터널 모드(Tunnel Mode)를 사용하는데, 이 방식은 기존의 IP 패킷 전체를 새로운 IP 패킷 안에 넣는 **캡슐화(Encapsulation)** 를 수행한다. 이후 새로운 IP 헤더를 추가하여 인터넷에서는 VPN 장비끼리만 통신하는 것처럼 보이게 된다.

캡슐화된 데이터는 **ESP(Encapsulating Security Payload)** 를 이용하여 암호화되어 제3자가 내용을 확인할 수 없으며 인증 기능을 통해 데이터가 변조되지 않았는지와 송신자가 신뢰할 수 있는 대상인지도 같이 결정한다.

목적지의 VPN 장비에서는 암호를 복호화하고 바깥쪽 IP 헤더를 제거한 뒤 원래 IP 패킷을 내부 네트워로 전달한다.

즉 IPSec을 이용하면 멀리 떨어진 두 네트워크도 하나의 내부 네트워크처럼 안전하게 통신할 수 있다.
