네트워크를 처음 배울 때 제일 많이 헷갈리는 게 이거다.

굳이 왜 나누지?

솔직히 처음에는  
그냥 하나로 처리하면 안 되나 싶다..

<br/>

근데 이걸 이해하려면  
전체 과정을 한 번에 보는 게 아니라  
**단계를 나눠서 처리하는 이유**를 먼저 봐야 한다.

---

## 왜 계층으로 나누는 걸까?

이걸 쉽게 생각해보면 “택배”랑 비슷하다.

택배 하나 보내는 과정도 보면

- 물건 포장  
- 주소 작성  
- 배송 처리  
- 이동  
- 전달  

이렇게 단계가 나눠져 있다.

<br/>

이걸 한 사람이 전부 처리하면 비효율적이다.

그래서 역할을 나누는 거다.

네트워크도 똑같다.

데이터를 보내는 과정이 너무 복잡하기 때문에  
각 역할을 나눠서 처리한다.

이게 바로 **계층 구조**다.

---

## OSI 7계층

> 네트워크 동작을 7단계로 나눈 표준 모델

OSI 모델은 “이론적으로 완벽하게 나눈 구조”다.

각 단계가 하는 일이 굉장히 명확하다.

---

### 1계층 (물리 계층)

> 실제 신호를 전송하는 단계

전기 신호, 케이블, 하드웨어 같은 부분이다.

데이터를 “0과 1”로 바꿔서 보내는 단계다.

---

### 2계층 (데이터 링크 계층)

> 같은 네트워크 내에서 데이터 전달

MAC 주소를 사용해서  
옆에 있는 장치까지 데이터를 보낸다.

오류 검사도 여기서 처리한다.

---

### 3계층 (네트워크 계층)

> 목적지까지 경로를 찾는 단계

IP 주소를 사용한다.

어디로 보내야 하는지 결정하는 “길찾기” 역할이다.

---

### 4계층 (전송 계층)

> 데이터 전달을 안정적으로 관리

TCP / UDP가 여기다.

데이터를 쪼개고, 순서 맞추고, 오류 체크까지 한다.

---

### 5계층 (세션 계층)

> 연결을 관리하는 단계

통신 시작 / 유지 / 종료를 담당한다.

쉽게 말하면 “대화 시작하고 끊는 역할”이다.

---

### 6계층 (표현 계층)

> 데이터 형식을 맞추는 단계

암호화, 압축, 인코딩 같은 작업이 여기서 이루어진다.

---

### 7계층 (응용 계층)

> 사용자가 직접 사용하는 단계

HTTP, FTP, SMTP 같은 것들이 여기에 포함된다.

우리가 웹 브라우저 쓰는 것도 여기다.

---

## TCP/IP 4계층

> 실제 인터넷에서 사용하는 구조

OSI는 이론적인 모델이고  
TCP/IP는 실제로 쓰는 구조다.

그래서 더 단순하다.

---

### 1계층 (네트워크 인터페이스)

OSI 1 + 2계층

물리적인 전송 + 같은 네트워크 내 전달을 담당한다.

---

### 2계층 (인터넷 계층)

OSI 3계층

IP 기반으로 데이터 경로를 결정한다.

---

### 3계층 (전송 계층)

OSI 4계층

TCP / UDP로 데이터 전달을 관리한다.

---

### 4계층 (응용 계층)

OSI 5 + 6 + 7계층

사용자가 직접 사용하는 영역이다.

---

## OSI vs TCP/IP 차이

정리하면 이렇게 보면 된다.

<br/>

OSI → 이론적으로 자세하게 나눈 모델  
TCP/IP → 실제로 사용하는 단순한 모델  

<br/>

OSI는 “설명하기 좋은 구조”  
TCP/IP는 “실제로 동작하는 구조”라고 보면 된다.

---

## 흐름으로 이해하기

데이터가 어떻게 이동하는지 보면 이해가 더 쉽다.

<br/>

사용자가 웹사이트 접속 (응용 계층)  
→ 데이터 형태 변환 (표현 계층)  
→ 연결 생성 (세션 계층)  
→ 데이터 분할 (전송 계층)  
→ 경로 결정 (네트워크 계층)  
→ 실제 전송 (물리 계층)

<br/>

그리고 반대로 올라오면서 다시 조립된다.

---

## 정리

처음에는  
왜 이렇게 복잡하게 나누는지 이해가 안 됐는데

정리해보니까  
결국 역할을 나누기 위한 구조였다.

<br/>

하나로 다 처리하면 복잡해지고  
문제가 생겼을 때 원인을 찾기도 어렵다.

<br/>

계층으로 나누면

- 역할이 명확해지고  
- 유지보수가 쉬워지고  
- 문제 추적도 쉬워진다  

<br/>

결국 핵심은 하나다.

**복잡한 걸 나눠서 처리하기 위해 만든 구조다.**
